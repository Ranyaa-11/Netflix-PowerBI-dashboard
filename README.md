# 📺 Netflix Dashboard

An interactive data visualization project analyzing Netflix content using IMDb scores, votes, runtime, release year, and age certifications. Built to demonstrate skills in **data cleaning, exploratory analysis, and dashboard design**.

---

## 🚀 Features
- **Data Cleaning & Transformation**: Prepared raw Netflix dataset using Python (Pandas)  
- **Exploratory Data Analysis (EDA)**: Identified trends in IMDb scores, votes, runtime, and release years.  
- **Interactive Dashboard**: Built in Power BI/Tableau with filters for type (Movie/Show) and release year.  
- **Visual Insights**:  
  - Distribution of IMDb scores by release year  
  - Votes vs. runtime correlation  
  - Age certification breakdown (R, PG-13, PG, NC-17)  
  - Total IMDb votes: **123M+**  



## 🛠️ Tech Stack
- **Languages**: Python (Pandas)
- **Visualization Tools**: Tableau / Power BI  
- **Data Source**: Netflix dataset with IMDb metadata  

---

## 🎯 Key Learnings
- How to clean and transform large datasets for analysis.  
- Building dashboards that communicate insights clearly.  
- Using storytelling with data to highlight content trends.
